## Especificações Técnicas

Todas as imagens seguem o mesmo padrão de implementação:

| Propriedade | Valor |
|-------------|-------|
| Componente | `next/image` |
| Carregamento | `loading="lazy"` |
| Aspect ratio | `aspect-[4/3]` (800×600 px) |
| Ajuste | `object-cover` |
| Formato | JPEG |

| `rh` | Recuperação de Hélices |
| `rtc` | Recuperação de Trocadores de Calor |
| `rth` | Fabricação e Recuperação de Transportadores Helicoidais |
